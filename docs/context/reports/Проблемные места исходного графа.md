# Проблемные места исходного графа

Исходный `example.osm` кейса без правок, проверка редактора на 10.11.2026. Координаты — широта, долгота. Ссылки открывают точку на Яндекс Картах. Решение по каждому месту принимается по знанию местности: редактор показывает, где данные противоречивы, но не знает, как на самом деле.

Править нужно в самом редакторе: по условиям кейса итоговый `.osm` записывает редактор, а QGIS при сохранении теряет отношения и часть тегов полос. Проект без правок: `/p/e3365725-0e94-4177-a97b-2d56a8fb0893`. Все места ниже есть в консоли внизу, щелчок по строке переводит карту к месту.

## 4. Что в исходном файле отсутствует совсем

- **Знаки приоритета:** ни одного 2.1, 2.4, 2.5. Все перекрёстки без светофора сейчас равнозначные. Задаются в карточке узла, раздел «Приоритет по ПДД».
- **Светофоры:** 2 узла со светофором. Остальные регулируемые перекрёстки нужно отметить по местности.
- **Остановки:** пункты «Мельниково» (2) и «Ломоносова» не входят ни в одну зону. Не влияет на SUMO, важно для модели ОТ в редакторе.

## 5. Что править не нужно

- 49 дорог без проезда в обе стороны в отчёте связности: почти все обрезаны рамкой файла, это свойство выгрузки, а не ошибка.
- Дворовые проезды `service`: по длине маршрутов улицы дают 87%, массово удалять проезды не нужно.
